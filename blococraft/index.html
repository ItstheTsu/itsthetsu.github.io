AINDA TEM DÚVIDA?

PERGUNTAS FREQUENTES.

Tudo para evitar dor de cabeça antes de entrar no jogo.

Qual versão do Minecraft eu preciso usar?

O servidor foi informado como Minecraft Java 1.20.1 com Forge. O Minecraft Bedrock não é a versão indicada para esse pacote.

Onde baixo o Forge?

Baixe apenas pelo site oficial do Forge. A build exata ainda depende da validação do conteúdo do modpack.

O botão já baixa um instalador .exe?

Não. Por enquanto, o link abre o pacote original disponibilizado pelo Google Drive. O instalador automático está pendente de testes com o pacote real.

Preciso apagar minha pasta .minecraft?

Não. Faça uma cópia de segurança e prefira criar um diretório/perfil separado para o modpack. Não apague mundos, screenshots e configurações pessoais.

O servidor está online agora?

Esta página é estática e não consulta o status em tempo real. Se não conectar, verifique se o servidor está ligado e se o modpack/Forge corresponde ao utilizado pelo grupo.
